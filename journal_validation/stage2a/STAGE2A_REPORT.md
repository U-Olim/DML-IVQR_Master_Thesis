## Findings

**Confirmed numerical effect:** pivotal penalty randomness alone can change the
true-parameter test decision on identical observations. One of 24 fixed
dataset/quantile settings crossed the rejection cutoff across ten independent
streams. All 24 settings showed numerical W variation.

**Confirmed numerical effect:** replacing the density-proxy scale argument
`var(e)` with `sd(e)` changes instrument nuisance regressions, residualized
instruments, and W. In the fixed-data experiment it changed 16 of 240 paired
decisions, concentrated on two fixed samples at tau=.90, kappa=1.

**Inconclusive for calibration:** the 40-replication paired pilot changed DML
coverage from .625 to .650, one acceptance gained. The paired difference is
.025 with estimated Monte Carlo SE .025. This does not establish restored
95% calibration or identify the cause of the archived .498 result.

All experiments completed. No new estimator warnings or numerical failures
were recorded. SHA-256 preservation checks covered 3,331 files outside this
Stage 2A directory: none changed, disappeared, or were added. The thesis,
journal manuscript, canonical wrappers/configuration, frozen outputs, and
historical library were preserved. Nothing was committed or pushed.

## Design and implementation controls

A used three independent primitive samples for each n in {500,1000}. Each
primitive sample was reused at kappa in {1,.10}; each resulting fixed dataset
was evaluated at tau in {.50,.90} under ten independent pivotal streams.
Thus A has 12 physical datasets, 24 dataset/quantile settings, and 240
baseline evaluations. Observations do not vary across streams within a setting.

B supplied one SD-proxy partner to every A evaluation: 240 pairs. C used 40
new samples at n=1000, tau=.90, kappa=1, with Oracle-GMM, Full-GMM, and
DML-IVQR-BC, each evaluated under both density variants: 120 pairs.
All tests evaluate exact `1+qnorm(tau)` against `qchisq(.95,2)` =
5.99146454710798. No grid profiles or 500-replication run were executed.

Both density variants use the same detailed candidate function. The alternative
is generated by replacing exactly one R syntax-tree node:

```r
dnorm(e, mean(e), var(e))
# becomes
dnorm(e, mean(e), sd(e))
```

Reversing that edit recovered the identical baseline syntax tree. Instrumentation
records intermediate quantities without changing solver arguments. The baseline
was checked against the actual sourced canonical candidate functions in 24
cases: both n, both tau, both kappa, and all three estimators. W, outcome
coefficients, residuals, residualized instruments, DML penalty vectors, and
final RNG states agreed exactly.

Every density pair resets the same full RNG state before each fit, on the same
worker. All 360 pairs had identical observations, outcome coefficients and
outcome residuals. All 280 DML pairs had identical pivotal penalty vectors;
the reconstructed Uniform-draw matrices had matching SHA-256 identities.
Every pair also had identical RNG end states. An independent consumption check
verified that DML used exactly the intended n*1000 Uniform draws, while
Oracle/Full consumed none. Instrument regressions added no random draws.
Worker scheduling therefore introduces no additional difference between partners.

The stream-control policy differs from the historical uncontrolled worker policy,
but is held fixed between the two partners. No unintended numerical code path
was found; this is a single-factor density-scale ablation conditional on the
recorded samples and streams. Changes in instrument-Lasso penalties/loadings
are downstream effects of changing its transformed data, not extra interventions.

The historical `hdm` 0.2.0 body overrides its instrument penalty constant to
c=.5 on this `post=FALSE` path. We preserved this behavior. The displayed
formal default c=1.1 alone does not describe this executed path. No tolerance,
intercept, post-Lasso, covariance, cutoff, or sample-splitting change was made.

All 16 flips were baseline rejection to alternative acceptance. They occurred

settings had mixed signs; the intervention does not uniformly reduce W.

Classification: **Confirmed numerical effect** on density weights, instrument
nuisances, residualized instruments, W, and some decisions. **No detectable
effect at tested settings** on outcome nuisances (exact equality, as expected)
and on numerical failure counts. This does not establish a valid conditional
density estimator or orthogonal score.

All entries use the same 40 new data samples. All 40 evaluations succeeded
for every estimator and variant. Parentheses contain marginal Wilson 95%
Monte Carlo intervals, not confidence intervals for structural effects.

The respective acceptance counts were 37/40, 21/40, and 25/40 for the baseline;
the DML alternative accepted 26/40. The sole discordant DML pair was baseline

was .025. For Oracle/Full the empirical paired-difference MCSE was zero

decision-change probability is zero.

## Recommendation for Stage 2B — proposed, not executed

Keep the SD proxy as a diagnostic variant, not a replacement for the canonical
estimator. This intervention changes numerics and can change decisions, but
the pilot offers only one additional DML acceptance and does not approach 95%.

The next priority is a small, prespecified paired decomposition using controlled
streams: known structural outcome nuisance versus estimated outcome nuisance,
then the preserved versus constant-inclusive correctly weighted instrument
projection. Record score centering and nuisance-orthogonality diagnostics, not
coverage alone. The changes in this experiment and the lack of decision changes
for Full-GMM motivate examining additional nuisance/projection components rather
than assuming the normal-scale argument explains the distortion.

Separately resolve the population density-weight regularity argument before
making theoretical validity claims. A larger coverage experiment should follow
an explicit scientific question and precision target, not serve to select a
favorable cutoff or implementation after seeing pilot outcomes.

**Not executed:** Stage 2B; known-nuisance or projection-intercept interventions;
cross-fitting; treatment-DGP modifications; full 500-replication runs; journal
edits. These remain proposals awaiting review.
