\section{Reproducibility and Implementation Notes}
\label{app:reproducibility}

The repository for this thesis is \href{https://github.com/U-Olim/DML-IVQR_Master_Thesis.git}{publicly available} and contains all the code needed to reproduce the reported results: \url{https://github.com/U-Olim/DML-IVQR_Master_Thesis.git}.

The preserved author-replication and main-extension environment is R~3.4.3 on 64-bit Windows. The main Monte Carlo uses $R=500$ replications per design and seed 675. The grid-domain diagnostic also uses seed 675 and reuses saved primitives in its second stage. The separate instrument-strength calibration uses seed 20260813. The frozen reporting outputs are exactly reproducible from the archived CSVs. The parent-process seed records the simulation setup, but because the preserved parallel DML implementation does not explicitly initialize worker-specific RNG streams, exact regeneration of all pivotal penalty draws from the seed alone is not established.

The reporting layer reads frozen simulation, calibration, and diagnostic outputs without re-estimating models. Reporting consistency checks and source/output hash manifests connect those records to the numerical tables. Figure-data checks verify all 480 plotted values against the frozen reporting CSVs, while the figure manifest records source and final-image hashes. Full supplementary tables, RMSE figures, detailed diagnostics, configuration files, and environment records remain in the repository even where they are not printed in the current PDF.

The 480-value figure check concerns the original archived figure set. The selected-figure validation additionally checks 120 coverage values, 120 full-domain acceptance frequencies, and 168 median rejection probabilities against final outputs. The appendix reporting step regenerates Table~\ref{tab:coverage-audit-summary} from saved direct-at-truth evaluations and checks the results against the frozen coverage audit. It also generates the analytical illustration in Table~\ref{tab:kappa-illustration} directly from the variance formulas. Neither step re-estimates models. The additional reporting outputs retain integer acceptance counts, unrounded Wilson endpoints, reconciliation checks, and input hashes.

An implementation-specific detail concerns the fitted-normal density proxy used in the DML-IVQR nuisance step. The preserved code calls \texttt{dnorm(e, mean(e), var(e))}. In R, the third argument of \texttt{dnorm} is interpreted as a standard deviation, whereas the preserved code supplies the residual sample variance. This behavior is retained to preserve the executable implementation used in the simulation study.
